# Walls That Talk

Street art histories across New York, Amsterdam, and São Paulo.

A static site built from the Walls That Talk Figma design. Clicking a ticket plays the train transition between pages, and the timeline draws itself as you scroll (both are Lottie animations in `lottie/`).

To preview locally (the animations need a server, not a double-clicked file):

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.
